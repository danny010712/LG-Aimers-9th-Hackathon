## 0. 실전 압축 요약 🔥

- 지도학습 = **(데이터, 함수클래스, 손실함수)** 정하고 손실 최소화하는 파라미터 찾기.
- **과적합 진단은 val loss로**: train≈val 좋음, train≪val 과적합. → 대회 리더보드=test, 절대 튜닝 대상 아님. 🔥
- 과적합 대응: 데이터↑, **규제(L2/L1)**, augmentation, **교차검증**, 단순한 모델(Occam).
- 최적화: 대규모/딥러닝은 **SGD → Momentum → RMSProp → Adam**. Adam이 기본값.
- 분류 지표: **Precision/Recall 트레이드오프 → F1**, 임계값 스윕 → **ROC/PR curve**. 문제에 맞는 threshold 선택. 🔥
- **"복잡한 문제 아니면 딥러닝 필요 없다."** 단순 문제엔 단순 모델(선형·NB·트리).

## 1. 지도학습 셋업 ⭐

- **분류(Classification)**: 라벨 이산/유한. **회귀(Regression)**: 연속/실수.
- 진짜 함수 `f*`를 함수클래스 `F`에서 근사하는 `f̂` 찾기.
- "잘 근사" = 모든 입력에서 같은 값(불가능) → **주어진 데이터에서** 손실 최소화.
- **Pointwise loss** (MSE, cross-entropy 등) → 전체 Loss = 평균.
- 규칙기반(rule-based)은 복잡 태스크 불가 → ML은 데이터가 규칙을 정하게.

## 2. 선형회귀 ⭐

- 모델: `ŷ = wᵀx + b`. 손실: **MSE** (미분가능 + analytic solution이라 선호. 절대오차·수직거리도 가능하나 불편).
- **Normal Equation** (closed-form): `ŵ = (XᵀX)⁻¹Xᵀy`. n+1 변수 선형방정식으로 해결.
- **다항/비선형 피처 추가** 🔥: `x → [x, x², ...]` 재정의하면 같은 선형회귀 틀로 곡선 적합. "언제나 피처 추가 가능 → 더 표현력, 단 과적합 주의." 피처는 inspection·전문지식으로 선택.

### 2-1. 과적합 & Bias-Variance Tradeoff 🔥🔥
| 상태 | 특징 |
|---|---|
| **Underfit** | High bias — 너무 단순, train도 못 맞춤 |
| **Overfit** | High variance — train≈0, 새 데이터 못 맞춤 |
| **Just right** | 일반화(generalization) |

- **인식법**: 고차원이라 시각화 어려움 → **validation set** 사용. train loss≈0인데 val loss≫train → 과적합.
- **Train/Val/Test 분리** 🔥: train ~80%(적합) / val ~20%(검증·의사결정) / **test=별도, 학습중 unknown (대회 상황!)**. val도 결정에 영향 주므로 최종 성능은 test로만.
- **과적합 대응** 🔥:
  - 데이터 더 얻기(비쌈) / 생성모델로 샘플(주의)
  - **Regularization**: 손실에 **L2 항** 추가. λ 크면 규제↑, 작으면 규제↓.
  - **Augmentation**: 도메인 불변성 이용(이미지 shift/flip/rotate/noise). **단 데이터 의존적** — '2'의 수평뒤집기는 '2' 아님.
  - **Cross Validation**: 데이터 부족 시 (sklearn KFold).
  - **Occam's Razor**: 가정 최소 설명이 대개 옳다 → 단순 모델 선호.

## 3. Gradient Descent (경사하강법) 🔥

- 딥러닝처럼 파라미터 수백만~수십억, 손실 복잡 → analytic 해 없음 → **경사로 최적화**.
- `f'(x)=0`은 local minimum일 수도. 전역 시야 없이 **기울기 방향으로 이동**.
- 알고리즘: 랜덤 초기화 → 매 스텝 `θ ← θ − η·∇L(θ)`. **η=학습률(learning rate)**.
- **학습률 튜닝** 🔥: 손실 너무 느리게↓ → η 키우기 / 손실 발산 → η 줄이기. 여러 랜덤 초기화 시도.
- **자동 미분 도구** 있으니 직접 계산 불필요.

### 3-1. SGD 계열 🔥
- **SGD (Stochastic GD)**: 데이터 많으면 샘플링해 gradient 계산(gradient는 선형이라 가능).
- **Mini-batch GD**: 배치 단위 (실전 표준).
- **단점**: plateau·local minima에 갇힘.

### 3-2. 옵티마이저 진화 🔥 (Adam이 기본)
| 옵티마이저 | 핵심 |
|---|---|
| **Momentum SGD** | gradient의 가중평균 누적(관성). β=0이면 일반 GD, β↑ 관성↑. 고정 LR |
| **RMSProp** | 최근 gradient 크기 평균으로 **LR을 원소별 조정**(element-wise 나눗셈) |
| **ADAM** | Momentum(1차 모멘트) + RMSProp(2차 모멘트) 결합 + bias correction. **사실상 기본값** |

- **LR 스케줄링** ⭐: exponential, adaptive(annealing) — 학습 진행에 따라 LR 감소.

## 4. 분류 (Classification) ⭐

### 4-1. Perceptron 📎
- Rosenblatt(1957). 선형분리 가능 가정. 장점: 해 있으면 수렴·매우 단순. 단점: 해 없으면 안 멈추고, 알 수도 없음.
- **0-1 loss는 미분 불가** → GD 못 씀.

### 4-2. SVM (Support Vector Machine) ⭐
- **Margin 최대화**(경계에서 가장 가까운 점까지 거리) → 강건.
- Convex(QCQP) 문제 → solver 존재, infeasible 여부 알려줌.
- **Soft-margin SVM** 🔥: 오류 허용 위해 **slack variable(penalty)** 도입 → 선형분리 불가 데이터도 처리.
- **Hinge Loss**: `max(0, 1 − y·f(x))`. 하이퍼파라미터 **C**: 크면 이상치 강하게 penalize, 작으면 일반 샘플에 집중.
- **Kernel** 📎: 선형회귀처럼 추가 피처(예: quadratic kernel)로 비선형 경계.
- 특징: **경계 근처 점만 고려**(support vectors).

## 5. Logistic Regression 🔥 (분류의 실전 베이스라인)

- **Soft guess**: hard(빨강/파랑) 대신 확률(70% 비). 
- **Logistic(sigmoid) function**: 매끈, 확률(0~1) 모델링.
- **Cross Entropy Loss** 🔥: 정답 사건에 높은 확률 줄수록 loss↓. 분포간 차이 = **KL divergence(=relative entropy)**. 미분가능 → **GD 적용 가능** (perceptron/SVM과 달리).
- Hinge loss vs Logistic loss 비교 가능(둘 다 0-1 loss 대체).

### 5-1. 다중분류 ⭐
- **1 vs others** 여러 이진분류, 또는 **Softmax**(logistic의 일반화): 지수화로 양수·합=1 → 라벨 확률분포.
- Logistic Regression ⊆ Softmax Regression.

### 5-2. 분류 평가지표 🔥🔥 (대회 직결)
- 출력이 확률 → **threshold** 결정. 0.5가 안전하나 문제에 따라 조정(예: covid 검사는 false positive 선호).
- **Precision vs Recall 트레이드오프** → **F1 = 조화평균**. 애플리케이션 따라 선택.
- **ROC curve**: TPR=TP/(TP+FN) vs FPR=FP/(FP+TN).
  - 항상 positive → TPR=FPR=1 / 항상 negative → 0 / 랜덤 → TPR=FPR (대각선).
- (Tabular 강의 보강: **불균형이면 PR curve/PR-AUC가 ROC보다 유의미**.)

## 6. Beyond — 그 외 지도학습 & 확장 📎

### 6-1. 딥러닝이 필요 없을 수도 🔥
- 문제 단순 → 모델 단순. 딥러닝은 overkill일 수 있음.

- **Naive Bayes** (스팸필터) ⭐: 해석가능한 명시적 모델. 이메일=단어 indicator 벡터. **Naive 가정: y 주어지면 X들 독립**. **Laplace smoothing**: 안 나온 단어 대비 카운트 1부터 시작.
- **Decision Tree** ⭐: 내부노드=결정, 리프=클래스(분류)/값(회귀). 분할기준: 분류=entropy(dispersion), 회귀=subset 분산. (→ Tabular 강의에서 심화)
- **앙상블**:
  - **Bagging**: 복원추출 부분집합, 병렬, **분산 감소**, voting/averaging.
  - **Random Forest**: 여러 트리 결합.
  - **AdaBoost**: 순차, 오분류 샘플에 가중↑, 예측 가중합. **편향 감소**.

| | Bagging | Boosting |
|---|---|---|
| 방식 | 병렬 | 순차 |
| 효과 | **분산↓** | **편향↓** |
| 집계 | voting/평균 | 가중 voting/평균 |

### 6-2. 지도학습 응용 예 📎
Super Resolution(CNN, pixel MSE), Object Detection(Faster R-CNN), **BERT**(마스크 예측 + 다음문장, Transformer), 이상탐지(가중 분류 loss).

### 6-3. 지도학습 너머 📎
- **Semi-Supervised**: 라벨 비쌈 → unlabeled 활용(augmentation, contrastive).
- **Generative Models**: 라벨 없이 `p(x)` 학습. GAN, **Diffusion**(score-based SDE).

## 7. 해커톤 적용 포인트 🔥

- **검증 설계가 곧 순위**: train/val/test 엄격 분리, 대회 test에 절대 튜닝 금지, val로 과적합 감시.
- **불균형·비용 반영 지표** 선택 후 threshold 최적화 (F1, PR-AUC).
- 딥러닝 옵티마이저는 **Adam + LR 스케줄** 기본. LR 발산/정체로 조정.
- 로지스틱 회귀는 빠른 확률 베이스라인, SVM/NB는 소규모·해석용 카드.
- **단순 문제엔 단순 모델** — 딥러닝 남용 말고 GBDT/선형 먼저.
